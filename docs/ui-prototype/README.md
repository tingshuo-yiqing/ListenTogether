# 一起听歌 · 精简交互原型

2026-10-01 根据用户调整后的 HTML 更新，保留暖白、松绿与柔杏色，合并重复入口并减少辅助信息。Android 尚未应用这套设计；v2 独立验收缺陷仍按 [verification.md](../verification.md) 跟进。

## 打开

下载并直接打开 [index.html](index.html)。**只需要这一个文件**：样式、脚本、9 张示意 SVG 封面与示例二维码全部内嵌，无依赖、无需服务，不连接真实房间、不播放音频。

桌面左侧预览五个页面，工具栏可切换浅色 / 深色与多屏总览，右侧可切换角色与异常场景。手机仅保留默认字号竖屏，以图标导航切换队列、点歌、聊天；仅底部迷你播放器可展开播放页。

## 可体验的流程

- 创建房间 → 空队列 → 点歌 → 首曲就位且暂停 → 点播放；再加歌后可切下一首，最后一首跳过后清空播放器。
- 加入房间 → 手填邀请码，或模拟相机 / 相册扫描 → 确认邀请 → 加入。切换创建与加入保留输入。
- 右上退出图标 → 确认退出；成员面板内查看二维码、复制邀请或分享。二维码在原面板展开，复制失败时提供可选择的邀请文本。
- 队列只展示待播歌曲的封面、歌名、歌手；当前歌曲集中在底部。房主长按 380ms 拖动排序，靠近边缘自动滚动；切页、掉线、角色变化或取消会结束拖动。键盘可聚焦歌曲行后按 Alt＋上下方向键排序。行尾菜单只保留移除，成员只能撤回自己的歌曲。
- 点歌仅显示加号，已点后变成勾号；随机图标每次加入一首。搜索歌名或歌手、清空、分页保留；成员最多 5 首待播，当前曲不计配额。
- 聊天草稿跨页保留；发送中 → 已发送 / 失败；右侧可模拟失败并使用原消息身份重试。模拟好友消息可检查未读和翻历史时的滚动位置。
- 点迷你播放器 → 封面、歌名、歌手、示意歌词上下排列。底部集中进度、播放 / 暂停与下一首；时间仅操作进度时显示。成员播放键只暂停或恢复本机跟听。
- 右侧切换成员身份、空队列、正在重连、版本不兼容；不兼容展示返回入口。

聊天保留发送者身份，省略每条消息的时间，发送中、失败与原消息重试仍然可见。上述状态均在浏览器内存中模拟，刷新即重置。系统分享与剪贴板使用浏览器能力；示例邀请码不会加入真实房间。封面与原创歌词用于排版，不代表真实专辑或歌曲原词。Android 的网络确认、拖排冲突、歌词跟随与输入法行为仍须实施后验收。
