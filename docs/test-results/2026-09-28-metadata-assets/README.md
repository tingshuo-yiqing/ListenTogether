# 匹配歌词与封面直接应用（2026-09-28）

状态：完成，本机与云端已更新。操作者：Codex。只修改管理器、共享资源模块、离线验证和文档，不改安卓或听歌协议。

## 使用与行为

- 点击「匹配这首」同时尝试LRCLIB歌词。来源文档：https://lrclib.net/docs 。歌名、歌手归一后相同，时长差≤10秒才选；优先带时间轴，否则允许纯文本并明确标注。无可信歌手时跳过，未命中/网络失败独立展示，不阻止文字和封面；文字源失败也继续尝试歌词。
- 表格新增封面、歌词勾选项。点击「应用所勾选字段」由服务器下载封面、写歌词文件并更新引用，无需另存或上传。匹配和预览本身不改曲库。
- 批量匹配缺字段包含缺封面和缺歌词，应用时只补空。**（单曲口径已由同日追加小轮改变：见文末「追加小轮」；批量只补空这一条不变。）**内嵌封面也视为已有。
- 封面下载失败按字段报告，歌词与文字仍可保存；歌词失败不写失败缓存。歌词成功/未命中缓存24小时，勾「忽略缓存重查」可强制刷新。
- 资源票据绑定歌曲、编目快照和30分钟有效期；修改曲目、管理器重启或过期后需重新匹配。服务端不接受客户端任意URL。
- 图片仅HTTPS受信QQ/网易/封面档案图床，每次跳转复验；超时12秒、封面≤1MB、歌词≤256KB、魔数校验。落盘用唯一文件名；整库校验失败恢复原编目、撤销新文件；旧资源保留供回退，不误删共享资源。
- 换曲丢弃旧匹配响应，未保存手工编辑时要求先保存再匹配。页面移除“手动另存封面”“云端不受影响”等过期说明；ID3参考文本改用textContent。

## 追加小轮（2026-09-28 晚：单曲匹配到歌词即默认勾选，应用即替换）

按用户指令「修改掉这个设置，匹配到歌词后就可以替换掉旧的歌词」调整默认勾选口径。上文「已有歌词（包括占位文件引用）不自动替换，要在单曲候选中主动勾选」**自本小轮起只对批量生效**。

- **口径**：`POST /api/tracks/:id/sync` 新增可选 `onlyIfEmpty`。单曲匹配（界面「匹配这首」，不带该参数）只要 LRCLIB 命中就把 `lyrics` 放进 `changes`，本曲已引用歌词也照放——界面默认勾选，点「应用所勾选字段」即替换。批量匹配（顶栏「批量匹配缺字段」）在 `/sync` 与 `/apply` 两端都带 `onlyIfEmpty: true`，已有歌词不进候选，一键补缺仍不会换掉整库歌词。封面维持原样：已有封面一律不自动勾（换图必须人工确认），所以「歌词替换、封面不替换」的不对称是刻意的。
- **替换的实质是换指针**：新文本另起 `lyrics/<id>-<uuid>.lrc`（`wx` 独占创建，绝不覆盖同名文件），catalog 的 `lyrics` 字段指向它；**旧 `.lrc` 原地保留不删**，因为同一份歌词可能被别的曲目共用，留着也便于把路径手工改回。写库仍过整库 `loadCatalog` 闸门，失败逐字节回滚并撤销新文件。
- **预览**：界面原有「预览匹配到的歌词」折叠块（候选全文前 2000 字）保持不变，用户确认「目前可以预览就不用加」。
- **验证**：`scripts/check.ps1 -Scope scripts` **37/37**（`metadata-assets.test.mjs` 的真实管理器用例已更新——原来断言「已有歌词时 changes.lyrics 为 undefined」，现断言单曲口径下等于本次票据、`onlyIfEmpty` 口径下为 undefined，并新增替换回归：应用后指针指向新文件、旧文件内容原样在盘）；管理器离线驱动 **85/85**（未改动，其 `/sync` 调用不带 `includeLyrics`，不受本口径影响）；Chrome UI 驱动 [browser-check.mjs](browser-check.mjs) 的模拟服务已按真实口径返回 `changes`，新增断言「已有歌词的曲目单曲匹配后只有 lyrics 被勾上、行文案含『已有歌词（已默认勾选』、提示含『旧 .lrc 保留原地』、批量 `/sync` 请求带 `onlyIfEmpty`」，实跑 PASS；该驱动会重写 [candidate-ui.png](candidate-ui.png)。另在临时 1 首曲库上用真实浏览器（browser-use）完整走一遍：选中已有 `lyrics/old.lrc` 的曲目 →「匹配这首」→ 歌词框默认 checked →「应用所勾选字段」→ toast「已应用…album、year、cover、lyrics」，盘上核对 catalog 指向 `lyrics/a-<uuid>.lrc`（新文件内容为候选文本），`lyrics/old.lrc` 仍是 `[00:00.00]OLD LINE 不要丢`。
- **边界**：只改本机 `scripts/` 与文档，未动服务端/协议/安卓，未碰真实 `media/`（验证全在一次性夹具目录，跑完即删）。**云端管理器 `listen-together-metadata` 仍是 20260928-metadata-02（旧口径）**，要生效需另发一版；客户端歌词缓存按曲目 id 存、换歌词不会自动失效（既有 `lyricsVer` 挂账），本轮未处理。


## 边界与清理

歌词源无结果就跳过，不无限重试，不保证所有版本都可命中；纯文本没有逐行跟随。超过1MB的远程封面报告失败，可用原有手动上传压缩入口。旧歌词客户端缓存失效和云端听歌后端独立封面支持不属于本轮，管理器保存后手机生效仍受既有部署/缓存边界约束。
本轮未做真机或全库批量公网抓取。临时音频/缓存/浏览器用户目录均在夹具结束后清理，真实曲库不用于删除/回滚测试。
