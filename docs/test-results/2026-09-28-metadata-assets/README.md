# 匹配歌词与封面直接应用（2026-09-28）

状态：完成，本机与云端已更新。操作者：Codex。只修改管理器、共享资源模块、离线验证和文档，不改安卓或听歌协议。

## 使用与行为

- 点击「匹配这首」同时尝试LRCLIB歌词。来源文档：https://lrclib.net/docs 。歌名、歌手归一后相同，时长差≤10秒才选；优先带时间轴，否则允许纯文本并明确标注。无可信歌手时跳过，未命中/网络失败独立展示，不阻止文字和封面；文字源失败也继续尝试歌词。
- 表格新增封面、歌词勾选项。点击「应用所勾选字段」由服务器下载封面、写歌词文件并更新引用，无需另存或上传。匹配和预览本身不改曲库。
- 批量匹配缺字段包含缺封面和缺歌词，应用时只补空。已有歌词（包括占位文件引用）不自动替换，要在单曲候选中主动勾选；内嵌封面也视为已有。
- 封面下载失败按字段报告，歌词与文字仍可保存；歌词失败不写失败缓存。歌词成功/未命中缓存24小时，勾「忽略缓存重查」可强制刷新。
- 资源票据绑定歌曲、编目快照和30分钟有效期；修改曲目、管理器重启或过期后需重新匹配。服务端不接受客户端任意URL。
- 图片仅HTTPS受信QQ/网易/封面档案图床，每次跳转复验；超时12秒、封面≤1MB、歌词≤256KB、魔数校验。落盘用唯一文件名；整库校验失败恢复原编目、撤销新文件；旧资源保留供回退，不误删共享资源。
- 换曲丢弃旧匹配响应，未保存手工编辑时要求先保存再匹配。页面移除“手动另存封面”“云端不受影响”等过期说明；ID3参考文本改用textContent。

## 边界与清理

歌词源无结果就跳过，不无限重试，不保证所有版本都可命中；纯文本没有逐行跟随。超过1MB的远程封面报告失败，可用原有手动上传压缩入口。旧歌词客户端缓存失效和云端听歌后端独立封面支持不属于本轮，管理器保存后手机生效仍受既有部署/缓存边界约束。
本轮未做真机或全库批量公网抓取。临时音频/缓存/浏览器用户目录均在夹具结束后清理，真实曲库不用于删除/回滚测试。
