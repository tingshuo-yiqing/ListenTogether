## 5. 判定标准

**长时（M3-LONG 判定，见 next-development-plan.md §4）**：

- 播放进度连续推进 70 分钟，无非预期暂停、重连、崩溃；报告所有缓冲与进度跳变。
- 息屏 ≥30 分钟窗口：以息屏前后位置差/墙钟差核算推进速率 ≈1x；息屏中 adb 空档如实标注（USB 连接下应无空档）。
- 诊断 `correction`：正常 Wi-Fi 下 `seek` 仅出现在大跨度拖动/真实失步，**无周期性 seek 风暴**；`speed`/`buffering` 分布记录。
- 状态采样不等于持续出声：解锁后由用户确认"一直在响"；息屏期间的连续性以位置推进 + 服务器 playing 状态 + 参与者（在线听着）听感三重印证。
- 日志截止与采样空档明确标注，缺数据区间不计为通过。
- 只对本设备（PHQ110）、本网络、本电池条件结论。

**多人（行为级判定）**：

- 每位参与者加入后 **10 秒内**追上房间进度出声（听感确认 + 服务器 member.joined→房间 version 时间差）。
- 任一参与者退出：其余人音乐不停（服务器 playing 不变、无 restart）。
- 房主退出：`host.transferred` 事件 ≤60 秒出现、播放不停；原房主重新加入 10 秒内追上。
- 非房主切歌：被 403 拒绝并有可见提示。
- 成员本地暂停：只影响自己（其余成员对照确认）。
- 息屏期间参与者加入/退出流程正常（服务器侧视角完整）。
- 蜂窝参与者（如有）：成功加入并稳定跟听 ≥10 分钟 = 蜂窝公网数据点成立。

## 6. 边界（如实标注，不得据此宣布）

- **M2 正式精度验收不在本轮**：参与者均远程、无法 adb 逐秒采样，"95% 采样偏差 ≤500ms + 同址录音比对"仍需一台可接 adb 的第二台手机，继续挂起（W5）。
- 诊断 JSONL 只覆盖重启后前 60 分钟（DiagnosticsLog 上限），其后媒体会话采样 + 服务器事件兜底，两段数据边界在结果中标注。
- 参与者设备型号/系统/网络各异，多人结论只对参与设备与本次网络条件成立。
- 参与者听感为主观确认（非录音），音频层一致性验收仍待 M2 录音方案。
- OPPO 已知行为：其他媒体前台约 33 秒后可能杀后台的本应用（陷阱 2.4）——参与者如遇中断重连属该行为，记录不复测。
- 流量：参与者每人 ≈86MB/小时（192k），4 人 80 分钟 ≈ 460MB 出网（20GiB/月额度内）。

## 7. 风险与预案

| 风险 | 预案 |
|---|---|
| 主测 USB 抖动（陷阱 2.2 device/offline 秒抖） | 采样脚本对 adb 失败记空档不中断；空档期间靠服务器事件兜底；必要时无线 adb 补连 |

| 顺播到歌单末尾 | 曲库 96.5 分钟 > 70 分钟窗口，且 demo-load 在末尾；若超时顺播触及末尾会自然停止（协议行为），按"最后一首播完停止"记录 |
| 参与者人数不齐 | ≥2 台参与者即可执行核心链路（加入/退出/转移）；人数不足时由主测手机第二账号分担角色 |
| 服务器异常 | Q-3 事件日志 + /health 计数实时观察；异常时 journalctl 取证；restart 是最后手段（会清房间，测试作废重跑） |

## 8. 结果（2026-09-24 执行完毕）

**结论：通过。** 长时（真实音乐 70 分钟 + 息屏 30 分钟）、多人动态进出、房主转移、无主房间边界全部达成；仅"非房主切歌被拒 / 成员本地暂停互不影响"两项因参与者中途全部离场未覆盖。

### 8.1 长时播放（M3-LONG 判定）

- **顺播 70 分钟（T0=11:03:03 → 12:13:34 暂停），真实音乐，零中断**：诊断 4988 条 playback（correction 分布：空 4845 / buffering 46 / load 14 / **speed 82 / seek 1**）；唯一一次 seek = E-07 主动拖回开头（合法大跨度拖动），**全程无周期性 seek 风暴**。speed 变速追赶 82 条（主测省电模式常开，符合陷阱 9.1 场景与分级纠正设计）。
- **曲目序列（诊断窗口内 14 首，全部自动顺切成功）**：有何不可 11:03 → 痴心绝对 11:07 → 单车 11:12 → 富士山下 11:15 → 句号 11:19 → 爱错 11:23 → 红豆 11:27 → 倔强 11:31 → 囚鸟 11:36 → 特别的人 11:41 → 大眠 11:45 → 爱情转移 11:49 → 背对背拥抱 11:53 → 王妃 12:00；诊断 60 分钟窗口到期（12:01，如期兑现 §6 边界）后停止写入，12:01-12:13 由 media_session 采样兜底（12:13:34 `PLAYING(3) position=248s speed=1.0`，仍在顺播中段）——**两段数据边界处播放连续**。
- 主测 WS **70 分钟只开过一次**（`socket-open` ×1，11:03:04，蜂窝网络）——无重连、无 Expired。
- 息屏 ≥30 分钟：**11:19 锁屏 → 11:49 解锁（Dozing 全程）**，v2 采样曲线连续 PLAYING、息屏中自动切歌 3 次、位置推进速率逐帧 ≈1.0x；解锁核对（自动 PIN 解锁成功）播放无缝。
- 顺播计时与曲库时长精确对账（11:03 + 49 分钟 = 爱情转移 1:42 处，误差 <2 分钟为建房间隙）。
