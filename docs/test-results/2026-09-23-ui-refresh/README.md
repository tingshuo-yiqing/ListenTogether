# 简洁 UI 开发与验证（2026-09-23）

## 本轮实现

- 首页使用创建/加入 Tab，保留昵称与服务器地址；邀请码仅在加入时显示。单个主按钮随路径切换，连接中禁用重复提交。
- 入房错误显示在主按钮上方，读屏可感知；正常连接收进人数摘要，本机暂停与异常继续展示。
- 房间码缩小、角色简写；成员默认折叠，展开包含在线/离线文字；歌曲列表去除重复底色，仅当前项高亮。
- 当前歌曲支持两行；MediaController 观测实际播放/缓冲/错误，以 mediaId 排除旧曲目数据。播放/跳转命令仍交给 RoomClient；校时完成才允许操作。
- 控制器监听按当前页面会话绑定与释放，断连清空观测；未连接不宣称播放中。
- 保留 64dp 主播放按钮、IME 适配、复制反馈、退出入口；进度待确认预览绑定曲目和会话。
- 本轮沿用现有 Material 滑块和动态主题；未实现自定义细轨道或正式默认服务器配置。
