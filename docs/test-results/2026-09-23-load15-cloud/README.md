## 边界（如实标注）

- 本轮为**服务端负载模型**（字节读取节奏化），不等于真机解码器拉动速率；真机公网播放行为已由 W2 公网 E2E 单独验证。
- 入口为明文 HTTP（路线 A，用户已决策），令牌明文传输属已知接受形态。
- **throughput（无节流）模型未在云端执行**：执行单第 4 节要求两类负载分开记录，但按任务书与 C6 流量预算本轮仅执行 playback 两轮（试跑+正式）；无节流全量读取会消耗额外流量，未纳入本轮预算。
- 1 秒粒度"部分字节秒"的连续性无法从汇总数据排除（见上节）。
- 服务器侧 CPU 未单独采样（C7 纪律限制为轻量命令，`free`/`journalctl`/`ss`/`/proc/net/dev`）；内存全程 ≥1175MB available、无 swap 使用迹象、NRestarts=0。
- demo-load 为合成测试音（正弦波），码率 192kbps 与真实曲目一致，仅频谱代表性有限（与本地轮口径一致）。
