## 环境与链路
- 设备：PHQ110（OPPO A1 Pro 5G / Android 14），无线 adb。
- 用户只提供配对端口与配对码（172.19.0.1:43419 / 658177）。实测：配对端口不能 connect（10060）；经 `adb mdns services` 取得调试端点 **192.168.43.15:39805**（`_adb-tls-connect`），配对记录已在，daemon 启动后 ~10s 自动回到 device 态。
- 本机演示后端已在 127.0.0.1:3000 运行（`/health {"ok":true}`）；`adb reverse tcp:3000/3001` 后设备端 `curl http://127.0.0.1:3000/health` 返回 `{"ok":true}`，端到端隧道打通。
- adb 每轮工具调用重启 daemon，故连接/reverse/操作在单进程内完成（见陷阱 2.7 坑 C/G）。
