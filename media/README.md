# 手动曲库

把有权分享的 MP3 放在本目录，编辑 catalog.json，例如：

```json
[
  { "id": "song-01", "title": "我的第一首歌", "file": "song-01.mp3" },
  { "id": "song-02", "title": "我的第二首歌", "file": "song-02.mp3" }
]
```

ID 为 1–64 位字母、数字、下划线或连字符且不得重复。文件必须位于本目录内，不能通过符号链接引用外部文件。
服务启动时读取真实 MP3 时长，不依赖人工填写时长。添加或修改文件后重启服务（内存房间会被清空）。
文件缺失或格式无效时启动失败并给出错误；运行期间文件被删除，音频接口返回 404。
不进行转码，优先用 128/192kbps MP3 测试。不要在播放中替换文件。
